## Lifecycle

Artifacts move through this lifecycle:

`Idea -> Research -> Architecture -> Approved -> Implementation -> Evaluation -> Review -> Published`

## Gates

| Gate | Minimum Evidence |
| --- | --- |
| Idea to Research | Problem statement, owner, initial scope. |
| Research to Architecture | Research notes, options, constraints, open questions. |
| Architecture to Approved | Architecture specification, related ADR path, review notes. |
| Approved to Implementation | Work package, acceptance criteria, evidence plan. |
| Implementation to Evaluation | Working artifact or capability increment and evaluation assets. |
| Evaluation to Review | Evaluation report, benchmark outputs, known limitations. |
| Review to Published | Review outcome, lessons learned, publication-ready summary. |

## Principle

The lifecycle is designed to make engineering state visible. It is not a process tax; it is the mechanism that keeps knowledge compounding.
