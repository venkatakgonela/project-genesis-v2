# Evaluation Metrics

## Purpose

Define shared metric vocabulary for the Evaluation Platform.

## Initial Metric Families

| Family | Example Metrics |
| --- | --- |
| Quality | Correctness, relevance, completeness, faithfulness. |
| Reliability | Pass rate, retry rate, failure rate, variance. |
| Efficiency | Latency, token usage, cost, throughput. |
| Safety | Policy violations, unsafe output rate, permission failures. |
| Grounding | Citation quality, evidence coverage, hallucination rate. |
| Maintainability | Debuggability, trace completeness, configuration complexity. |
