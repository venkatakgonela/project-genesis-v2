## Purpose

Project Genesis V2 is the engineering operating system for building reusable enterprise AI capabilities and future business applications.

## Mission

Create a version-controlled, evidence-led engineering system that separates planning, architecture, implementation, evaluation, evidence, and publishing.

## Strategic Principles

- Platform before application.
- Artifacts before conversations.
- Evidence before opinions.
- Evaluation from day one.
- Deterministic code before LLMs.
- Model agnostic.
- Architecture before implementation.
- Knowledge compounds.
- Continuous review.
- Learning is a deliverable.

## Scope

In scope:

- Programme governance artifacts.
- Architecture baseline and capability model.
- ADR structure and placeholders.
- Technology radar and evaluation framework.
- Evaluation platform scaffold.
- Platform capability specifications.
- Business application placeholder for Career Intelligence.

Out of scope for WP-001:

- Python implementation code.
- LangGraph implementation.
- FastAPI implementation.
- AI Gateway implementation.
- Production infrastructure.
- Runtime services.

## Success Criteria

WP-001 succeeds when the repository can guide future work packages without requiring undocumented conversations to reconstruct the architecture intent.
