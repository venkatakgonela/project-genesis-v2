## Objective

Assess MCP and tool runtime options for governed Project Conductor tool use in agentic workflows.

## Scope

- Tool discovery.
- Tool invocation boundaries.
- Permissioning.
- Tool evidence capture.
- Runtime isolation.
- Tool registry integration.
- Compatibility with agent framework choices.

## Candidate Technologies

- MCP.
- ToolHive or equivalent managed tool runtime.
- Direct local command tools.
- Repository-specific tool registry.
- Agent framework-native tool adapters.

## Evaluation Criteria

- Governance fit.
- Security and permission boundaries.
- Evidence capture.
- Integration with Project Conductor registry.
- Agent framework compatibility.
- Operational complexity.
- Migration risk.
- Enterprise credibility.

## Expected Evidence

- Tool invocation scenario analysis.
- Permission model proposal.
- Evidence capture requirements.
- Candidate comparison matrix.
- Integration risks and constraints.

## Expected Deliverables

- Evaluation report.
- Recommendation.
- Evidence pack.
- ADR-DRAFT-022 update.
- Inputs for ADR-009.

## Definition of Done

MCP and tool runtime options are assessed for agentic Project Conductor and no tool runtime is implemented.
