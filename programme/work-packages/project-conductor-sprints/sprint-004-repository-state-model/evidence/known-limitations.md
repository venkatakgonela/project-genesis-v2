# Sprint 4 Known Limitations

- No generated Repository State persistence.
- No Repository History.
- No Repository Diff.
- No Git integration or branch awareness.
- No database.
- No quality gate workflow.
- No AI, agents, MCP, LangGraph, AI Gateway, Prompt Platform, Context Platform, Knowledge Platform, Browser Automation, or application capability.
- Default generated timestamp is deterministic rather than wall-clock time.
- Repository State schema is implemented as Python dataclasses and Markdown documentation, not a machine-readable JSON Schema artifact.
