# Objective

Create the definitive Product Definition and Operating Model for Project Conductor.

The output should clearly describe:

* what Project Conductor is
* who uses it
* what problems it solves
* how users interact with it
* how it operates
* how it integrates with the rest of Project Genesis

This is a product specification.

Not an architecture specification.

Not an implementation design.

Not a technology evaluation.

# Mission

Project Conductor should become the operational brain of Project Genesis.

Its purpose is to help humans and AI systems work together effectively.

It should:

* understand programme state
* understand current work packages
* understand architecture
* understand ADRs
* understand repository state
* understand evidence
* prepare context
* generate prompts
* coordinate execution
* support reviews
* recommend next actions
* reduce drift
* maintain continuity

Project Conductor should not be tied to Career Intelligence.

Career Intelligence should become an application that uses platform capabilities.

Project Conductor must remain reusable across future applications.
