# Technology Discovery Programme

This folder contains the authoritative WP-003 Technology Discovery Programme for Project Genesis V2.

## Documents

| Document | Purpose |
| --- | --- |
| `technology-discovery-programme.md` | Defines the overall programme and capability area coverage. |
| `technology-discovery-process.md` | Defines the discovery-to-implementation process. |
| `technology-evaluation-framework.md` | Defines reusable evaluation criteria and evidence expectations. |
| `technology-adr-lifecycle.md` | Defines how technology evaluations become ADRs. |
| `technology-decision-gates.md` | Defines gates that block premature implementation. |
| `technology-watch-process.md` | Defines continuous technology scanning and review cadence. |
| `technology-discovery-backlog.md` | Lists future discovery areas by capability. |
| `technology-discovery-work-package-sequence.md` | Sequences WP-003A through WP-003K. |
| `technology-discovery-final-review.md` | Reviews WP-003 against its requirements. |

## Rule

No technology may be implemented solely because it appears in this folder. Implementation requires evaluation evidence, ADR approval, architecture approval, and an implementation work package.
