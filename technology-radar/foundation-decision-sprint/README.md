# Foundation Technology Decision Sprint

This folder contains WP-005 artifacts for the minimum technology decisions required before Project Conductor implementation can be planned.

## Documents

| Document | Purpose |
| --- | --- |
| `project-conductor-dependency-analysis.md` | Analyzes responsibilities, dependencies, interfaces, and blockers. |
| `foundation-technology-decision-list.md` | Lists only the technology decisions that block Project Conductor. |
| `technology-evaluation-work-packages.md` | Defines WP-005A through WP-005D. |
| `recommended-execution-sequence.md` | Orders the evaluations by dependency. |
| `draft-adr-backlog.md` | Lists draft ADRs that should result from the evaluations. |
| `programme-impact-assessment.md` | Assesses impact on programme readiness and implementation gates. |
| `foundation-decision-final-review.md` | Verifies WP-005 against its requirements. |
| `agentic-scope-alignment-report.md` | Corrects the agentic scope gap in WP-005A-D. |
| `project-conductor-layered-capability-model.md` | Defines Project Conductor Layers 0-3. |
| `missing-agentic-technology-decision-list.md` | Classifies missing assisted and agentic technology decisions. |
| `updated-wp-005-decision-map.md` | Maps WP-005A-J to layers, sequence, and ADRs. |
| `updated-wp-005-execution-sequence.md` | Defines the updated deterministic, assisted, and agentic execution order. |
| `adr-backlog-update.md` | Adds ADR-DRAFT-017 through ADR-DRAFT-022. |
| `contradiction-resolution.md` | Resolves whether excluding agentic technologies from WP-005 was correct. |
| `agentic-scope-final-review.md` | Verifies WP-005E scope alignment against requirements. |

## Rule

This sprint minimizes research. WP-005A-D cover the deterministic MVP. WP-005E-J cover assisted and agentic Project Conductor layers. Browser automation and deployment technologies remain excluded unless they directly block a Project Conductor layer.
