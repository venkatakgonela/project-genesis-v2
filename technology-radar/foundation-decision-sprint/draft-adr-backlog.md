## Relationship to ADR-002

ADR-002 Project Conductor remains the capability-level ADR.

The draft ADRs in this backlog are technology and implementation-enablement ADRs. They should not replace ADR-002. They should support it.

## Excluded ADRs

No draft ADR is created for:

- Agent framework selection.
- AI Gateway implementation.
- Model provider selection.
- Prompt Platform tooling.
- Context Engineering tooling.
- Browser automation.
- Deployment platform.

Those decisions do not directly block Project Conductor.
